# 贪吃蛇(伪三维多层版)

单文件网页小游戏,纯 HTML/CSS/JS,无任何外部依赖,双击 `index.html` 即可在浏览器中运行。

- 仓库: `D:\linshi\opencode`(git 已初始化,分支 `master`)
- 入口文件: `index.html`(所有代码都在此文件内)
- 提交约定: 每个功能版本一个 commit,格式 `vN: 简述`,提交信息为中文

## 游戏机制

### 基本设定
- 白底黑蛇:圆形蛇头(带白色眼睛与红色分叉吐信,随方向转动)、圆角身体胶囊连接、尾部两节渐细(v38)
- 画布 400×400,网格 20px,即 20×20 格
- 蛇初始位置头 (10,10),向右移动,初始长度 5(身体向左排开)(v38)
- 吸引演示:未点开始时,一条半透明灰色演示蛇在棋盘上随机游走(穿墙、不计分不吃果),点"开始"后消失(v29)
- 顶部提示(toast):每 100 分、首次穿墙/首次撞身爬层/首次吃到特效果果时,画布顶部居中弹出约 1 秒提示,新提示直接顶替旧提示
- 音效:吃果子(按种类不同音高)、升降层、反转、通关各有合成提示音;默认关闭,控制栏按钮开关
- **游戏手感(v75)**:吃果时按果子颜色的粒子爆花(金果 16 颗),扣命时红色粒子+画面震屏 200ms,护盾格挡蓝色粒子,开门绿色粒子;结算界面显示本局战报(到达层数/最长连击/吃果数)

### 穿墙与左右楼梯(v49)
- **上下边缘**:照旧原层环绕(从对侧穿出,不会死)
- **右边缘 = 上行梯**:从右边缘穿出**升一层**;**左边缘 = 下行梯**:从左边缘穿出**降一层**(第 1 层时照旧环绕)
- 换层复用爬层动画(↑ 翻页 / ↓ 回页)与升降统计;首次使用有一次性教学提示
- **限时模式主动换层扣 5 秒**(被动撞身/撞墙升层不扣;剩余时间保底 1 秒防瞬间结算);无尽/有命模式换层零代价(v49 不死限制精简版)
- 永不因穿墙死亡

### 撞自身 = 爬层(伪三维核心机制)
- 蛇头撞到同层蛇身/蛇尾时**不会死亡**,而是"爬上一层":
  - 蛇头先升到第 N+1 层(在该层同一坐标继续前进)
  - 背景视图立即切换到新层(每层是独立的 20×20 棋盘,与旧层分开)
  - 蛇身保持跟随模型,一节一节从下层"跟出来"
- 每层各自维护自己的果子;旧层的棋盘和果子保留,回到该层时原样呈现
- 各层之间蛇节互不碰撞(碰撞判定只针对同层蛇节)

### 蛇影投影(v66,老板提案)
- 游戏画布外的大片留白不再是纯色:整张网页垫一层**全窗口影子画布**,把当前层的蛇身与果子按"棋盘铺满窗口"的比例**放大投影**到留白上,影子与真实蛇的行进实时对应
- 蛇影 = 三层放大低透明度圆角块叠出软边(不使用 ctx.filter,规避全屏画布合成垫白问题);果子影 = 带自身颜色的淡色方块
- 影子颜色跟随皮肤:经典=墨影、翠玉竹林=竹绿影、赛博 2077=霓虹青影(暗底发光效果);未开始时投影演示蛇,页面像"桌面下有蛇在游"
- 影子画布 `pointer-events: none`,不影响任何操作;窗口缩放自适应

### 皮肤系统(v63)
- 三套皮肤:**经典**(白底黑蛇,默认)/ **翠玉竹林**(淡竹青底+竹叶青绿蛇+红信)/ **赛博 2077**(暗夜蓝底+霓虹青蛇+全身光晕,对照 ART-Zcode.md 留档方案实现)
- 皮肤只改**配色与观感**,玩法/判定/果子颜色完全不变(果子高饱和主色在三套皮肤下通用)
- 控制栏"皮肤"按钮在已解锁皮肤间循环,选择随存档持久化;未解锁的隐藏皮肤不占按钮档位
- 隐藏皮肤解锁方式不写进文档(保持惊喜);解锁时机何地输入均可,解锁弹 toast 提示
- 赛博皮肤发光用"放大低透明度光晕"实现(不用 shadowBlur,遵守美工稿性能红线);页面背景与画布边框随皮肤联动

### Boss 层大门(每 10 层,v62)
- 第 10/20/30… 层生成时自带一扇**锁定的大门**:右边缘上行梯被锁住,锁定期间从右穿出只做**本层环绕**(不算换层,限时模式也不扣秒)
- **开门条件**:在该层吃满 3 个果子(任意种类),大门开启,右梯恢复升层;开门前每次吃果弹"大门进度 N/3",开门弹"大门开启!"
- 右上角显示大门状态(红色 N/3 / 绿色"大门已开启"),画布右缘中段画门:灰底红杠=锁定,绿门脉动=开启
- 大门只锁**主动右梯**;粉果升层、撞身/撞墙被动爬层、左梯降层均不受影响(核心机制不动)

### 连击系统(v61)
- 连续吃果子累计**连击数**;每吃 1 个果子刷新 20 秒连击计时,超时未吃任何果子则"连击中断"归零
- **分数倍率**:每 8 连击倍率 +1(×1→×2→×3→×4→×5 封顶),当前倍率显示在连击 HUD(得分下方,橙色)
- **断连**:吃炸弹(含无敌期)、被扣命(踩陷阱/命尽)立即清零;20 秒不吃中断并提示
- 里程碑提示:8/16/24/32 连击时弹出"连击 ×N!分数 ×M!"
- 与双倍分果相乘:双倍(×2)× 连击(最高 ×5)= 最高 ×10 得分

### 层障碍物(第 2 层起,v27,v55 加密)
- 从第 2 层起,每层随机生成 4–7 个"墙格"(层数每 +2 上限 +1,最多 +4,高层最高 11 个);蛇头撞上墙格**强制爬上一层**(墙格保留在原层,可反复触发)
- 墙格画成白底黑框 + 浅灰斜纹(与"纯色方块=果子"的视觉语言区分)
- 生成避让:墙格避开蛇身/果子/蛇头落点,果子生成同样避开墙格

### 陷阱格(第 2 层起,v55)
- 从第 2 层起,每层随机生成 1–3 个"陷阱格"(每 3 层 +1,最多 3 个);样式为深色坑底 + 灰色尖刺
- 蛇头走进或停在陷阱格**扣 1 命**(三种模式通用,是继炸弹果之后第二种会死人的东西);扣命后 2 秒无敌闪烁防连扣,无敌期踩陷阱无效;命尽结算"命用完了!"
- 生成避让:陷阱避开蛇身/果子/墙格/蛇头落点;果子与传送落点也避开陷阱;相邻层陷阱以 0.15 透明度虚影预览

### 果子系统
- 每层同时存在 3 个果子,吃掉后在**本层**随机补一个
- 果子**不写文字**,只有颜色区分,效果由玩家自行探索(见下表)
- 果子生成时避开本层蛇身与本层已有果子

| 红 `#f00` | 普通:+1 分、+1 节 |
| 绿 `#0a0` | 限时加速 6 秒(速度 −60ms),左上角显示剩余秒数 |
| 蓝 `#06c` | 限时减速 6 秒(速度 +60ms),左上角显示剩余秒数 |
| 黄 `#c90` | 蛇身 +3 节(净增长) |
| 紫 `#a0c` | 蛇身 −2 节(最少保留 2 节) |
| 橙 `#f80` | 方向键反转 8 秒,右上角显示倒计时 |
| 粉 `#f0f` | 上层果子:升一层 |
| 青 `#0cc` | 下层果子:降一层 |
| 彩虹(动画渐变+黑描边) | 随机触发已有 8 种效果之一 |
| 金 `#fd0` | +51 分(+1 基础 +50 奖励),蛇身不变长;**残血时回 1 命(上限 3)**(v68) |

| 蓝紫 `#90f`(黑边) | 磁铁 8 秒:蛇头 2 格内果子自动入口——**炸弹也会被吸进来**!(v69) |

| 黄绿 `#9f0` | 丰收:本层果子各复制一份,至多 9 个(v69) |
| 深灰 `#666` | 传送:蛇头瞬移到本层随机空格,蛇身随后跟出 |
| 白 `#fff`(黑描边) | 时钟果:清空快/慢限时效果,速度回到基准 |
| 暗红 `#a00`(白边) | 炸弹果:扣 1 命(三种模式都可能出现,扣命后 2 秒无敌;第 1 层与新层首批不出现) |
| 银灰 `#ccc`(金边闪烁) | 双倍分:10 秒内所有得分 ×2(含金果奖励) |

- **第 1 层(开始层)= 安全出生层**:不会出现粉/青上下层果子,也**不会出现炸弹果**;从第 2 层起,20 种果子随机出现(炸弹果基础 2 份,第 5 层起 +1 份、第 9 层起再 +1 份;有命模式从第 5 层起额外再 +1 份,v68;禅模式全程无炸弹;元旦/五一/国庆期间金果 +2 份,v72)

- **层深度收益(v36)**:层越高,金果/彩虹果在随机池中份数越多(每 3 层 +1 份,最多 +3 份)——爬层从"事故"变"追求";同时高层的墙格数量上限微增(每 5 层 +1,最多 +2)

- 吃果子 +1 分;速度公式: `max(75, min(600, 滑块值 − min(80, score×2) − min(32, (层−1)×4) − (加速中?60:0) + (减速中?60:0)))`(v68 心流调参:40 分才满速、层数加速减半、底限 50→75ms = 满速约 13 格/秒;此前 v54 曾恢复 `×5 封顶−100`+`−8/层`,配空棋盘尚可,配上 v55 雷区后 20 分即满速 20 格/秒,真人实测 92 分即喊太难)

### 游戏模式(v35 起三选一,v71/v72 扩至六选一)
- **无尽**(默认):经典玩法;炸弹果与陷阱会扣命(共 3 命,右上角显示"命 ×N"),命尽结算;通关线 999999999 仅此模式有效
- **有命**:3 条命;吃"炸弹果"或踩中陷阱扣 1 命,扣命后 2 秒无敌闪烁防连扣(无敌期均无效);**吃金果可回 1 命(上限 3)**;命尽结算
- **限时**:180 秒倒计时冲分(顶部居中,最后 10 秒变红);时间到结算;**暂停时倒计时冻结**
- **每日**(v71):固定种子模式——按当天日期生成随机种子,**当天全网玩家拿到完全相同的果子/墙/陷阱布局**,比拼同一张图的高分;顶部显示当天日期;每天 0 点自动换图;最高分独立记录
- **迷雾**(v71):只有蛇头周围一圈可见,其余被浓雾覆盖(相邻层虚影同样被雾盖,HUD 自动反色);靠记忆和探索爬层,胆大心细
- **禅**(v72):没有炸弹、没有陷阱,墙保留(撞上只是爬层),零死亡压力纯享爬层
- **竞速鬼影**(v72,无尽模式专属):打破单局纪录后,你的"影子"会被保存(localStorage,最长 8000 步);之后每次无尽模式,半透明影子按当年最佳路线同层同跑——同层时可见,追上并超过它!新纪录诞生时提示"新影子诞生!"
- 各局结束显示**统一结算界面**:模式名、得分、该模式最高分(破纪录标注"新纪录!")
- 六种模式各自记录最高分;局中切换模式会被拒绝并提示

### 通关条件
- 分数达到 **999999999** 即通关:显示"通关!"界面,蛇停止,点"开始"再来一局(仅无尽模式)
- 三种模式都可能因炸弹果/陷阱扣光 3 命而结束(走统一结算界面);限时另有时钟到结算;重开点"重新开始"或结算后点"开始"

### 成就系统(v70 建,v74 扩充至 21 项)
- **21 项成就**,覆盖爬层(首次登楼/单局第10层/首次走楼梯下楼)、分数(100/500)、连击(16/32)、大门(首开/累计3扇)、吃果(累计100/500)、图鉴(10种/全20种)、四新果集齐、金果回命10次、隐藏皮肤、999999999 通关彩蛋,以及四种模式的专属成就(v74):每日打卡(每日 50 分)/雾中行者(迷雾到第 5 层)/禅心已久(禅到第 20 层)/超越影子(无尽分数超影子纪录)
- 解锁瞬间:顶部 🏆 toast + 双音号角;成就面板**双列**布局,绿勾/灰字,未解锁也显示名称与条件(给玩家下一个目标)
- 成就进度随存档永久保存;新增统计项:累计开门数、金果回命次数、历史最高连击

### 大屏自适应画布(v74)
- 画布按窗口尺寸自动放大:逻辑网格恒为 20×20,格子像素 20px→最多 30px(画布 400→640px),大显示器上棋盘更有存在感
- 蛇头/吐信/眼睛、墙格、陷阱尖刺、大门、鬼影、迷雾半径全部按缩放因子 PX 等比缩放;图鉴/成就面板按画布比例 U 自适应布局
- 刷新页面即可按当前窗口重新取尺寸

### 存档与图鉴(本地保存)
- localStorage 键 `snake3d_save`,版本化结构 `{v:2, best:{endless,survival,timed}, sound, stats:{climbs,descents,fruits}, book}`
- v1 旧档自动迁移:原 best 填入 `best.endless`,其余字段无感保留
- **最高分**:按模式分别记录;开始界面、暂停界面、结算界面显示当前模式的最高分
- **音效开关状态**跟随存档持久化,刷新页面后保持
- **战绩统计**:累计升层次数、降层次数、各类果子累计吃掉个数
- **果子图鉴**(v46 起独立):控制栏"图鉴"按钮打开,游戏中自动暂停;吃过某种果子才点亮其颜色与效果说明(含累计个数),未吃过的显示"?"占位(不泄露外形/颜色),保持探索感;图鉴由 `FRUIT_DESC` 常量表驱动,新增果子类型自动进图鉴

## 代码结构(单文件 `index.html`)

分区: CSS → HTML(画布 + 控制栏)→ JS

### 关键全局变量
| 变量 | 说明 |
| --- | --- |
| `snake` | 蛇节数组,每节 `{x, y, z}`,`z` 为所在层,`snake[0]` 为蛇头 |
| `dir` / `nextDir` | 当前方向 / 缓冲方向(防一帧内反向) |
| `started` / `paused` / `cleared` / `settled` | 已开始 / 已暂停 / 已通关(无尽) / 已结算(有命命尽或限时到时,v35) |
| `mode` / `lives` / `timedEndsAt` / `invincibleUntil` / `bestAtStart` | 当前模式 / 剩余命数 / 限时截止时间戳 / 无敌截止时间戳 / 开局时最高分(结算判新纪录用)(v35) |
| `score` | 分数 |
| `fastUntil` / `slowUntil` / `doubleUntil` / `ghostUntil` | 快/慢果、双倍分、隐身各限时 buff 的截止时间戳,0 表示未激活(快慢互斥;v34/v36) |
| `reverseUntil` | 方向反转截止时间戳,0 表示未激活 |
| `layers` | 层对象 `{z: {fruits: [{x,y,type}], walls: [{x,y}], traps: [{x,y}]}}`,惰性创建;第 2 层起含墙格(v27)与陷阱格(v55) |
| `FRUIT_STYLES` | 果子类型 → 颜色映射 |
| `BASE_POOL` | 普通层果子随机池(第 2 层起追加 `up`/`down`) |
| `toastMsg` / `hintsShown` | 顶部提示当前内容 / 一次性探索提示标记(v24) |
| `soundOn` / `audioCtx` / `FRUIT_PITCH` | 音效开关 / Web Audio 上下文 / 果子类型→音高映射(v25) |
| `save` / `SAVE_KEY` / `FRUIT_DESC` | 本地存档对象(localStorage 键 `snake3d_save`)/ 键名 / 图鉴效果说明表(v26) |

| 函数 | 职责 |
| --- | --- |
| `tick()` | 步进循环:按动态速度用 `setTimeout` 递归执行 `step()` |
| `frame()` | 渲染循环:`draw()` 挂 `requestAnimationFrame` 独立刷新(v20 起) |
| `step()` | 前进一格:穿墙 → 撞墙格/同层碰撞爬层 → 吃果子(上下层果调整 `head.z`)→ 末尾结算陷阱扣命(v55) |
| `climbIfColliding(head, body)` | 同层碰撞则 `head.z+1` 并 `ensureLayer`,最多循环 10 次 |
| `drawWall(x, y)` | 绘制墙格:白底黑框 + 浅灰斜纹(v27) |
| `fillFruitShape(type, px, py, size)` | 绘制果子:彩虹动画渐变、双倍分金边脉动、隐身半透明、炸弹白边、时钟黑描边;主层/虚影/图鉴共用(v28/v36) |
| `eat(f, z)` | 加分数/通关判定、补果子、长短/快慢/反转效果、炸弹扣命 |
| `settle(reason)` | 统一结算:有命命尽('dead')/限时到时('timeup'),显示结算界面(v35) |
| `loseLife(msg)` | 统一扣命:命 −1,归零结算,否则 2 秒无敌;炸弹果与陷阱共用(v55) |
| `drawTrap(x, y)` | 绘制陷阱格:深色坑底 + 灰色尖刺(v55) |
| `draw()` | 绘制当前层蛇与果子、相邻层果子虚影、爬层动画、顶部提示与覆盖层(开始/暂停/通关) |
| `reset()` | 重置全部状态,回第 1 层 |
| `ensureLayer(z, avoid)` / `randomFruit(z, avoid)` / `randomWall(z, avoid)` / `fruitPool(z)` | 层的懒创建、果子/墙格生成(带落点避让)与果子随机池 |
| `togglePause()` | 暂停切换并同步按钮文字 |
| `controlsReversed()` | 判断是否处于方向反转状态 |
| `showToast(text)` / `showHint(key, text)` | 顶部 1 秒提示;探索提示每种只弹一次(v24) |
| `ensureAudio()` / `tone()` / `playSound()` | Web Audio 合成音效,默认关(v25) |
| `loadSave()` / `persist()` | 读档(带结构与版本校验,坏档回默认)/ 写档(v26) |
| `resetDemo()` / `demoStep()` | 吸引演示蛇的初始化与随机游走(仅未开始时步进)(v29) |

### 蛇身跟随模型(重要)
每步先保存 `old = snake` 快照,再 `snake = [head, ...old.slice(0,-1)]`——每节继承前驱的旧位置(**含 z 坐标**),所以爬层后蛇身会自动一节节跟上,无需额外逻辑。吃果子时用 `[head, ...old]`(净 +1),长短果再额外 push/pop。

### 输入处理
- 用 `e.code` 判断按键(`ArrowUp` 等),并忽略 `e.isComposing`,保证**中文输入法下方向键、空格仍可用**
- 空格: `started && !cleared && !settled` 时切换暂停;方向键: 同条件下改 `nextDir`,并拒绝直接反向

## 开发注意事项(给后续接手的 agent)

1. **单文件**: 所有改动集中在 `index.html`;不要引入外部库或额外文件
2. **每版提交 git**: 改动完成后按 `vN: 中文简述` 格式提交
3. 保持既有设定: 白底黑蛇、仅方向键、撞墙/撞身不死亡(爬层)、撞自身爬层;死亡压力统一走炸弹果/陷阱扣命管线(v55)
4. 改果子颜色时注意区分度(现有 8 色: 红/绿/蓝/黄/紫/橙/粉/青)
5. 若加新机制,更新本文档的机制说明与版本历史表
6. **新增瞬移/传送类机制必须避让陷阱格**(现有传送果已避让;陷阱判定在 step 末尾,瞬移落点要同时避开墙/果/陷阱/蛇身,见 v58 复查建议)
6. 验证方式: 浏览器打开 `index.html` 手动试玩(无自动化测试)
